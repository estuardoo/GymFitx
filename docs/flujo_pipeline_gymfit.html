Flujo del pipeline GYMFIT

Dos figuras que se enlazan: la sesión en vivo (cámara → puntaje) y el camino del dataset al modelo, que vuelve a la sesión como un comparador más. Cada paso indica el módulo de src/ que lo ejecuta. Haz clic en cualquier paso (o en su icono i) para abrir una ventana con el detalle y las funciones de sus módulos.

Dónde queda cada cosa

  • datos/grabaciones/ — video crudo, features y metadatos de cada sesión
  • datos/plantillas/ — toma de referencia calibrada por ejercicio
  • datos/clips/ y manifest.json — los segmentos exportados y su índice
  • datos/etiquetas.json — etiquetas de los cortes
  • datos/entrenamientos/run_N/ — modelo, meta.json y gráficas de cada corrida
  • datos/config.json — servidor y base de SQL Server
  • datos/gymfitx.log — el único log del proyecto
